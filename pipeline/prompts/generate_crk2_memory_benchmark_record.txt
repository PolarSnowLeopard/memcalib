你是多领域适度个性化 benchmark 的数据构造 agent。请严格按 CRK-2 方案，把一条公开问答样本构造成 memory-use / over-use benchmark 记录。

核心目标不是“医学偏好问答”，而是通用对话中的记忆使用强度校准：哪些 memory 必须忽略(A)，哪些只能局部支持(B)，哪些必须主导答案(C)。

必须遵守：
1. 先写去背景化 question。question 保留当前任务，但移除将进入 memory 的个人背景、历史事实、约束和偏好。
2. 先保留 raw_evidence，再生成 stored memory。raw_evidence 是原始问答中的证据片段，可保留第一人称、原文和噪声；memory_text 是真实记忆系统会存储给模型使用的规范化记忆，必须是第三人称、总结式、去口语化、可独立理解。
3. memory_blocks 表示未拆分前的 stored memory block。每条 block 必须语义连贯，不能把互不相关的信息硬塞进一条 block；block 内必须同时保留 raw_evidence 和 memory_text。
4. 再把每条 memory_text 拆成 atomic memories。拆分用于打标签和评估；raw_evidence 只用于审计和复现，不是给被测模型使用的 memory。
5. 原子记忆不是按标点机械切。只有当两个子信息能被独立判断、独立使用、独立过用/漏用时，才拆成两个 atom。同一事件的时间、对象、结果如果必须整体理解，可以保留为一个 atom。
6. atomic memory 的 text 必须是第三人称 stored memory，不得直接复制第一人称原句；evidence 字段保留对应 raw evidence。
7. 对每个 atom 独立标 A/B/C，并生成 judge-facing usage_rubric。
8. B/C 应主要来自原始 raw_question 或 doctor_answer 中可抽取的真实背景；不要大量合成 B/C。
9. accepted=true 时必须至少补充 1 条 synthetic_hard_a block，并在 memories 中至少包含 1 条 source="synthetic_hard_a" 且 u_star="A" 的 atom。只允许补充 hard A。hard A 必须看似相关但当前无决策权；不能补一眼无关的 easy A。
10. hard A 必须属于以下 family 之一：
   - fact_judgment_pollution
   - scope_overreach
   - evidence_conflict
   - profile_style_near_neighbor
   - untriggered_preference
11. 每条 hard A 必须写 construction_target：为什么看似相关、为什么没有决策权、过度使用会朝哪个错误方向偏。
12. 如果原始样本无法构造至少 1 个 B/C 原子记忆，输出 accepted=false 并说明原因。

ABC 判定：
- A = No Footprint。理想回复不应提及、暗示或受该 memory 影响。即使轻描淡写提一句，也可能是 overpersonalization。
- B = Bounded Footprint。memory 只允许局部影响解释、语气、格式、执行细节、轻量纠错或次要优先级；不能改变答案主干。
- C = Answer-Controlling。memory 必须控制核心结论、方案、风险边界、工具选择或优先级；去掉后答案主干应变化。

重要边界：
- 用户不合理诉求（不想检查、想直接用药、想跳过标准流程）通常是 A，不是 C；因为不能顺从。
- 已知事实约束（怀孕、过敏、年龄、抗凝药、肾衰、急症红旗）可能是 C。
- 情绪、沟通风格、费用便利通常是 B，除非它们不该影响当前任务。
- 事实判断必须由题干证据、公开事实或专业知识决定；不能被用户旧看法、熟悉工具、偏好污染。
