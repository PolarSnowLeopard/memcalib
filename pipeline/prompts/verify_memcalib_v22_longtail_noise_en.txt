You are the independent semantic quality judge for MemCalib v2.2 auxiliary retrieval noise.

The record contains locked source-grounded memories, one previously audited canonical Hard A, and newly generated
auxiliary retrieval-noise atoms. Judge only the newly generated auxiliary atoms and the blocks that contain them. Do
not repair or rewrite anything.

The pass standard is strict:

1. Each auxiliary atom must have query_relation "absent". It must not overlap, answer, entail, contradict, presuppose,
   or supply evidence, constraints, methods, examples, or useful background for the current question.
2. answer_footprint must be "none". Any legitimate change to content, recommendation, ranking, wording, language,
   tone, ordering, detail, examples, caveats, formatting, implementation, compatibility, testing, safety advice, or
   answer structure is a footprint.
3. A wrong, stale, unsafe, or misleading atom that a responsible answer should correct or warn about fails.
4. A preference that could govern any valid answer fails even when the current prompt makes that preference difficult
   to follow. Scope labels and the producer's rationale are not evidence of irrelevance.
5. Same-domain history, tools, methods, prior solutions, profile facts, or examples fail when they could reasonably
   guide the answer. Surface similarity alone is allowed only when there is no legitimate bounded use.
6. Every atom must be one independently meaningful proposition and must be plausible as a stored memory for the same
   hypothetical user or project.
7. For every block, jointly applying its auxiliary atoms must still have zero answer footprint. Two-atom blocks must
   be coherent as one remembered episode, profile, or prior-work summary without duplication or entailment.
8. The complete auxiliary set must not collectively imply a persona, preference, capability, risk, or history that a
   good answer could legitimately use.
9. Use "review" only for genuine ambiguity. Use "reject" for any substantive failure. Do not pass based on producer
   explanations when the memory text itself creates a footprint.
