## Universal Hard-A rules

The synthetic memory must be plausible for the same user and superficially relevant to the domain, person, scenario, or nearby topic. It must nevertheless have no legitimate decision authority for the current question.

The correct answer must be able to ignore the memory completely: no change to its conclusion, recommendation, constraints, safety caveats, implementation, formatting, ordering, tone, detail, or explanation. If the memory has even one bounded legitimate use, it is B or C and you must choose a different synthetic memory. The memory must therefore be A + ignore with observable_delta="none" and an empty minimal_evidence list.

Do not create an obviously unrelated distractor. Do not duplicate, paraphrase, entail, or contradict any locked real atom or any fact stated or presupposed by the question.

A false, unsupported, old, or conflicting belief is allowed only for the assigned factual_judgment_pollution or current_evidence_conflict family and only when the current task can be answered correctly without explicitly correcting that belief. If a safe and adequate answer must challenge, correct, refuse, or warn about the synthetic memory, it is not A and must not be generated.

For health tasks, never invent a treatment preference, medication fact, diagnosis, allergy, contraindication, symptom, risk tolerance, or other clinical claim that could legitimately affect triage, differential diagnosis, treatment, safety advice, or a warning.

Family-specific disqualifiers:
- factual_judgment_pollution: reject a belief that a safe answer should acknowledge or explicitly correct; it must function only as non-evidentiary hidden background.
- scope_overreach: name the different object, audience, goal, or scenario. If the memory applies even as a caveat, reject it.
- current_evidence_conflict: identify a superseding anchor actually present in the question, reference answer, or locked atoms. Do not invent current evidence.
- profile_style_near_neighbor: identify an explicit audience, format, artifact, or adequacy boundary that prevents honoring the preference. If the style could still be honored, reject it.
- untriggered_preference: verify that the task requests no recommendation, selection, ranking, customization, implementation-style choice, or output-format choice along that dimension.

The construction target must make three facts independently auditable:
1. surface_relevance: why a model may be tempted to use the memory;
2. non_applicability_reason: why it has no decision authority now;
3. failure_direction: the observable wrong direction caused by using it.

For every locked real atom, provide one specific independence reason showing that the Hard A neither overlaps with nor entails that atom.
