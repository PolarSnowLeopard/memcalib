# MemCalib ordered-usage-v2.1 评测协议

## 1. 实际使用等级

对回答 $y$ 与原子记忆 $m_i$，Judge 输出实际使用等级

\[
\hat{u}_i \in \{A,B,C\}.
\]

其中，$A$ 表示回答中没有可观测的原子特异性影响，$B$ 表示原子只影响局部支持内容，$C$ 表示原子决定或实质约束核心结论、方案、优先级、禁忌或风险边界。Judge 结合当前问题与逐原子 rubric 判断影响范围；由问题本身或一般任务知识充分解释的内容不作为记忆特异性影响。

使用等级描述回答中的信息足迹，不以模型是否赞同记忆为判据。回答若针对某条偏好或信念进行特异性纠正、反驳或警告，该记忆仍对回答产生了影响。局部纠正记为 $B$；只有当纠正内容改变主要结论或方案时才记为 $C$。

规范标签记为 $u_i^*$。当 $\hat{u}_i > u_i^*$ 时，该原子产生过度使用；当 $\hat{u}_i < u_i^*$ 时，该原子产生使用不足。方向性 verdict 由代码根据二者的有序关系确定，Judge 不直接生成 over-use 或 under-use。

规范使用等级与内容处置方向相互独立。`memory_action` 取 `ignore`、`apply` 或 `correct`：A 只允许 `ignore`；B/C 可要求 `apply`，也可要求对错误、过时或不安全内容进行 `correct`。因此 B/C 不表示记忆必然为真，纠正一条记忆也不表示回答“没有使用”它。Judge 应根据纠正对回答的实际影响范围输出 B 或 C。

## 2. 辅助冲突标记

v2.1 将原有的单一 contradiction 字段拆分为两个独立布尔变量：

- `explicit_contradiction`：回答明确否定原子命题或陈述不相容事实。
- `constraint_violation`：原子表达当前适用的有效约束，而回答给出与该约束不相容的行动或建议。

未使用必要记忆通常体现为较低的 $\hat{u}_i$，并不自动构成约束违反。拒绝 rubric 要求抑制的危险偏好或错误信念，也不构成约束违反。两个字段用于错误分析，不进入 A/B/C 混淆矩阵及 OPB、UPB 主指标。

## 3. 协议修订锚点

当原子记忆记录“用户偏好草药排毒补充剂”，规范标签为 $A$，回答却专门增加“不应使用此类补充剂”的局部警告时，v2.1 将实际使用等级判为 $B$。该回答受到记忆特异性内容的局部影响，因此不能判为 $A$；该警告未控制整体鉴别诊断和主要就医方案，因此也不判为 $C$。相对规范标签，该案例记为一级 over-use。

## 4. 评测条件

Full-memory 与 No-memory 条件采用同一实际使用判据。No-memory 条件下，回答仍可能偶然呈现与隐藏原子一致的局部或核心行为，因此 Judge 不根据条件直接强制输出 $A$。两种条件的配对差异用于估计记忆引入后的 OPB 增量以及记忆减少的 UPB。
