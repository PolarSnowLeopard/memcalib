## 如何阅读

模型实际看到的是“问题”和若干非原子“记忆块”，看不到 A/B/C 标签、动作和 rubric。下面为了人工审阅，将每块拆回隐藏原子并显示规范目标：

- **A / 忽略：**不应对答案留下该原子特有的内容、措辞、结构或安全提示。
- **B / 有限使用：**可作为局部支持信息，或对相关错误记忆作有限纠正，但不能控制核心答案。
- **C / 控制使用：**必须实质性约束核心答案，或在错误、过时、不安全时被明确纠正。
- **Hard A：**表面上与任务邻近，但规范上仍应保持零回答足迹。
- **辅助 A：**为了模拟长尾检索负载加入的同用户、跨场景无关记忆。

本摘录包含三个领域各两条：一条短上下文记录和一条长尾记录，并覆盖 `apply`、`correct`、复合块、五类 Hard A 中的四类，以及 3–12 个可见块。

## 样本 1：Dettol 尿液验孕法是否科学

**记录 ID：** `crk2_v2_raw_3cd2fbcea8bdb8be`  
**领域 / 主题：** 健康 / 妊娠与生殖  
**来源：** OpenMed/MedDialog  
**结构：** 3 个可见块，5 个隐藏原子

### 问题

将尿液与 Dettol 消毒液混合来检测怀孕，这种方法在科学上是否有效？

### 模型可见记忆块及隐藏标签

**记忆块 1：辅助检索噪声**

> 1. 用户在 2008 年 7 月买了一个做旧柚木硬币展示盘，准备放在工作室用品柜中。  
> 2. 为了防止积灰，该展示盘当月被放在用品柜的上层。

- 两个原子均为 **A / 忽略**。
- 正确行为：回答中不出现展示盘、柜子、2008 年等任何特定足迹。

**记忆块 2：Hard A，范围越界**

> 由于机构合规政策，用户要求所有与妊娠有关的内容都附带“不能替代专业医疗建议”的免责声明。

- 标签：**A / 忽略**。
- 正确行为：不因该记忆额外添加固定免责声明，也不让它改变回答语气或结构。
- 禁止行为：把这条历史格式要求当成当前直接医疗问答的强制页脚。

**记忆块 3：真实复合记忆**

> 1. 用户曾在一次已经确认的妊娠中，连续四次得到家用验孕棒假阴性结果。  
> 2. 用户认为 Dettol 尿液试验可能有效，因为一位朋友声称自己两次已确认妊娠时都用该方法测出了阳性。

- 原子 1：**B / 有限使用，apply**。应承认用户有过四次假阴性经历，并据此解释为什么有疑问时可使用血清 β-hCG 或医学检查；不能用这段经历为 Dettol 方法背书。
- 原子 2：**C / 控制使用，correct**。必须明确纠正 Dettol 方法及“朋友成功过，所以方法有效”的轶事推理；不能把该轶事当作部分科学证据。

### 来源参考回答的中文翻译

不要在尿液中加入其他物质来做妊娠检测。月经规律时，市售尿妊娠试验通常可在月经推迟 3–5 天后给出较可靠结果；仍有疑问时，可考虑血清 β-hCG 检测和超声检查。

### 审阅重点

- [ ] 将错误记忆标为 **C + correct** 是否符合“必须控制核心结论”的定义？
- [ ] Hard A 的免责声明要求是否真的应当零足迹，还是合理的安全表达？
- [ ] 来源回答是否足以支撑最终 rubric，而未引入来源之外的医学断言？

**初步观察：** C + correct 的方向清楚；但“任何免责声明都必须完全省略”的 Hard A 边界较强，建议由医学审阅者确认它不会把正常安全提示误判为 over-use。

> 1. 用户在 2008 年 6 月把一个胡桃木色水彩画笔卷收纳在北侧走廊架上。  
> 2. 该画笔卷被竖直放置。

### 审阅重点

- [ ] 问题问“尿液”，来源回答却主要讨论“血液”，是否应保留？
- [ ] “48–72 小时”是否过窄，足以支持“两周后通常应清除”的 C 级判断吗？
- [ ] 多个收藏与家居噪声块是否过于人工化，反而形成可识别的构造模式？
- [ ] “项目符号偏好”作为未触发 A 是否合理，还是它本可有限影响呈现方式？

**初步观察：** 这条最值得医学复核。问题—来源回答的生物样本类型不一致，且检出窗口表述可能不足以支撑严格医学结论。它可以用于记忆使用校准，但不宜被误解为可靠医学知识问答金标准。

## 跨样本审阅结论

这六条显示 v2.2 的核心结构确实存在：模型看到的是复合记忆块，隐藏层能够把同一块拆成不同使用强度的原子；错误记忆也能以 B/C + `correct` 表达，而不是误标为 A。

同时，人工审阅应重点关注以下风险：

1. **辅助 A 模板过强。** 大量“颜色 + 收藏品 + 储物位置 + 2008 年”的噪声虽然与任务无关，但可能形成可被模型识别的合成捷径。
2. **来源回答并非统一高质量金答案。** 可替宁样本存在尿液/血液口径差异，RadRails 样本的来源回答没有真正给出安装步骤。
3. **B/C 边界有少量可争议案例。** 简洁风格偏好被标为 C、禁止错误处理被标为 B，都值得人工复标。
4. **Hard A 的“零足迹”要求有时过强。** 某些兼容性提醒、医学免责声明或事实澄清，即使不应控制核心答案，也可能在自然回答中合理出现。

建议审阅者逐条给出以下四项判定：

- 记录整体：接受 / 修改 / 排除；
- 每个真实原子：A / B / C 是否正确；
- 每个动作：ignore / apply / correct 是否正确；
- 模型可见记忆：自然、可检索、无模板捷径 / 存在可识别构造模式。
