Technical summary

研究问题正在转向“影响是否合度”

早期长期记忆研究主要衡量信息能否被保存、检索与回忆；近两年的评测开始考察记忆进入回答之后是否产生恰当影响。MemCalib 位于这一新阶段，其价值取决于对“影响强度”与“监督粒度”的进一步形式化。

01 / FIELD SHIFT

长期记忆能力与记忆使用校准构成两个不同的评估层次。LoCoMo、LongMemEval 和 MemoryAgentBench 重点覆盖回忆、时序推理、更新与遗忘；RPEval、OP-Bench、BenchPreS 和 StratMem-Bench 已将研究焦点推进到选择性使用与过度使用。[5][6][12][14]

02 / CLOSEST PRIOR ART

RPEval 与 StratMem-Bench 是最直接的概念邻居。前者已经使用 Ignore / Support / Dominate 的三级偏好标签；后者已经区分 required / supportive / irrelevant 记忆。三级角色本身不宜作为 MemCalib 的优先性主张。[12][14]

03 / DISTINCTIVE POSITION

MemCalib 的主要区分度来自表示层与评价层的分离。模型接收现实记忆系统可能返回的非原子总结块，评估端保留隐藏原子命题、逐原子规范标签和可观察 rubric，从而能够识别同一可见记忆块内部的混合使用要求。

04 / CLAIM BOUNDARY

当前版本适合主张“异质长期记忆的原子级有序使用校准”。“通用对话 benchmark”仍需更多非医疗数据源支持；“首个过度个性化评测”“首个三级记忆策略评测”等表述均会与近期工作发生直接冲突。[11][12][13]

建议定位：MemCalib 研究异质长期记忆在回答生成中的适度影响。它在模型侧保留非原子记忆形态，在评估侧以隐藏原子命题和实例化 rubric 描述每条信息应当产生的影响等级，并通过实际等级与规范等级的有序偏差同时测量过度使用与使用不足。

Nearest neighbors

四项最近邻工作分别占据不同的重叠区域

MemCalib 的论文叙事需要正面讨论这些工作，并把差异落到可验证的设计对象上。笼统使用“选择性记忆”“适度个性化”或“超越事实回忆”难以形成充分区分。

RPEval

标签空间最近
已覆盖
对每条偏好标注 Ignore、Support、Dominate；多偏好样本使用 A/B/C 对齐标签；同时包含显式记忆与对话化隐式记忆。[12]
关键重叠
三级规范使用强度与双向偏差意识。MemCalib 不应把 A/B/C 划分本身作为首创。
主要差异
RPEval 聚焦偏好及意图推理；MemCalib 覆盖事实、偏好、约束和安全敏感信息，并评价回答中的实际影响等级，而非仅预测使用策略或按生成错误类型评分。
写作位置
应作为最核心的相关工作，定位为从“偏好利用推理”扩展到“异质记忆的响应级影响校准”。

StratMem-Bench

任务语义最近
已覆盖
在虚拟角色对话中区分 required、supportive、irrelevant 记忆，要求使用全部 required、选择性加入 supportive 并抑制 irrelevant，同时评价整合质量。[14]
关键重叠
从事实回忆推进到策略性使用。“必要—支持—无关”三分法已有明确先例。
主要差异
其模型输入由独立记忆条目组成，使用判断近似二值；MemCalib 保留非原子父记忆，允许一个可见块内部包含不同规范标签，并以 A/B/C 描述实际影响足迹。
写作位置
应强调“memory item selection”与“within-block atomic calibration”的区别，并承认其在角色对话和整合质量上的更强覆盖。

BenchPreS

选择性权衡最近
已覆盖
在 39 个正式沟通情境中，以人工一致标注判断偏好属性应当应用或抑制，并通过 Misapplication Rate 与 Appropriate Application Rate 呈现过度应用和恰当应用之间的权衡。[13]
关键重叠
同时关注“错误应用”和“应当应用却未应用”。这与 OPB / UPB 的双向测量动机高度一致。
主要差异
BenchPreS 采用二值 apply/suppress，范围集中于第三方正式沟通中的表达偏好；MemCalib 采用三级影响强度，并覆盖更广的记忆类型与问答后果。
写作位置
MemCalib 应突出有序强度和原子级 rubric，同时借鉴其三人一致保留机制加强人工验证。

OP-Bench

过度使用最近
已覆盖
从长程对话构造 1,700 条验证样本，将过度个性化划分为无关、重复与谄媚，并显示加入记忆后各类系统都会出现明显退化。[11]
关键重叠
过度个性化是记忆系统的独立失效模式。这一问题定义和风险叙事已有直接前作。
主要差异
OP-Bench 以问题和失败类型诊断过度方向，未对每个原子给出所需使用等级，也不对使用不足进行对称建模。
写作位置
可将其视为失败模式 benchmark，将 MemCalib 表述为可同时定位过度与不足、并追溯到具体原子的校准 benchmark。
MemCalib position

核心单位是“可见记忆块中的隐藏原子影响”

真实记忆系统通常返回一句或一段总结，其中包含若干相互关联的信息。MemCalib 在模型输入中保留这种非原子形态，并在评估端拆解为独立可判断的原子命题。这一分层使 benchmark 能够处理同一记忆块内部的差异化使用要求。

ui*, ûi ∈ {A, B, C};   ûi > ui* ⇒ over-use,   ûi < ui* ⇒ under-use

其中，ui* 表示原子记忆 i 的规范使用等级，ûi 表示 Judge 从回答中识别出的实际影响等级。A、B、C 依次表示无可观察的原子特异性影响、局部且受限的支持性影响、决定或实质约束核心回答的控制性影响。实际等级高于规范等级时记为过度使用，低于规范等级时记为使用不足。

01 / REPRESENTATION

非原子输入与原子监督分离

保留部署时更常见的总结式记忆块，同时允许在隐藏层面对多个紧密相关事实分别标注。混合标签父记忆直接检验模型能否在同一块内选择性使用信息。

02 / MEASUREMENT

有序的实际影响等级

评价对象是回答中的信息足迹及其控制范围。与二值“使用 / 未使用”相比，三级有序判断可以识别局部提醒被放大为核心限制等中间失效。

03 / SCOPE

异质记忆与实例化 rubric

同一协议覆盖案例事实、画像事实、偏好、约束与安全敏感信息。逐原子 rubric 将标签语义落到当前问题中的可观察行为，降低抽象类别的解释漂移。

04 / SCALE

可复现的大规模响应评测

当前冻结版本包含 15,526 条样本、56,031 条模型可见记忆块和 78,726 条隐藏原子标注，可在同一原子级协议下形成完整 A/B/C 混淆矩阵。

Contribution boundary

贡献应建立在组合设计与测量对象上

近期论文已经快速覆盖选择性偏好、过度个性化和策略性记忆。稳健的贡献陈述需要避免单个概念的优先性竞争，转而说明 MemCalib 解决了哪些此前评价单位难以表达的案例。

可支持的主张

  • 面向异质长期记忆的原子级有序使用校准 benchmark。
  • 在模型可见的非原子记忆块下，利用隐藏原子监督评价差异化使用。
  • 通过同一 A/B/C 混淆矩阵对过度使用与使用不足进行对称测量。
  • 以实例化 rubric 连接抽象使用等级与回答中的可观察行为。
  • 为 Judge 训练或强化学习提供结构化、逐原子的监督信号。

应避免的表述

  • “首个超越事实回忆的策略性记忆 benchmark”：StratMem-Bench 已明确提出该定位。
  • “首个 Ignore / Support / Dominate 三级标签体系”：RPEval 已采用同构标签。
  • “首个过度个性化 benchmark”：OP-Bench 已系统定义并验证三类 OP。
  • “首个评估偏好应否应用的 benchmark”：BenchPreS 已提供二值选择性评测。
  • “覆盖通用对话”：当前冻结版本的数据来源仍集中于医疗对话，应使用“任务定义具有通用性，当前实例以医疗来源为主”。

建议用于论文摘要或引言的定位句

MemCalib evaluates calibrated memory influence in dialogue generation. The benchmark preserves realistic, non-atomic memory blocks as model input while maintaining hidden atomic propositions and instance-specific usage rubrics for evaluation. This design enables ordered, atom-level measurement of over-use and under-use across heterogeneous memory types, including cases where a single visible memory block contains information with different desired roles.
Limitations & next steps

当前证据支持任务价值，广泛性主张仍需补强

现有全量评测证明协议能够产生稳定的原子级方向性差异，但相关工作比较也暴露出四项需要在论文提交前处理的证据缺口。

优先事项相关工作带来的比较压力建议补强
HIGH
扩展非医疗数据源		 RPEval 覆盖日常偏好，BenchPreS 覆盖正式沟通，StratMem-Bench 覆盖虚拟角色对话。当前 MemCalib 样本来源难以支撑强“通用对话”结论。 按任务域、记忆类型和冲突结构增补一般助理、生活规划、教育、消费与协作场景；保持统一原子化和 rubric 协议。
HIGH
扩大人工有效性验证		 BenchPreS 使用三名标注者一致保留，StratMem-Bench 对使用判断采用多次 Judge 投票。自动构建与 LLM Judge 需要更强人工锚点。 对来源、标签、父记忆是否混合、记忆类型和难度分层抽样；报告 gold 标签一致率、原子边界一致率与 Judge 有序加权 κ。
MEDIUM
补充检索条件		 OP-Bench 和 MemoryAgentBench 直接比较记忆增强系统，能够观察检索策略造成的错误。MemCalib 当前主要衡量给定记忆后的下游使用。 保持核心 benchmark 的系统无关性，同时增加 retrieval-aware track，区分“检索错误”“给定后使用错误”和二者交互。
MEDIUM
避免单一 H 排名		 全量五模型 H 分数极差约为 0.028，而 A/B/C 标签正确率最大跨度约为 0.124，说明聚合总分压缩了模型间行为差异。 主结果同时报告 OPB、UPB、H、完整混淆矩阵和按标签 / 记忆类型分层结果；H 用于平衡概括，不单独承担排名结论。
总体判断：MemCalib 已经拥有可辨识的研究位置，最强叙事是“在真实非原子记忆表示下进行原子级、双向、有序的影响校准”。下一阶段的主要任务是扩大领域覆盖和人工验证强度，使这一方法学位置获得与其数据规模相匹配的外部有效性。
