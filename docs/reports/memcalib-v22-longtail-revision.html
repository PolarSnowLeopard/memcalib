MemCalib v2.2 长尾记忆块修订与质检

从锁定的 v2.1 基础集出发，将每条记录从固定两块扩展为 3–20 块长尾负载，同时保证每条记录至少一半可见块可拆成多个独立评分原子。

本报告只描述 v2.2 增量修订；公共数据源抽样、源语义质检、A/B/C 基础标注和 canonical Hard A 构造沿用 v2.1 锁定结果。

3. 3–20 块长尾分配

设第 i 条记录的可见块数为 Ki，其多原子块目标为 Mi：

3 ≤ Ki ≤ 20
Mi = ceil(Ki / 2)

这条约束逐记录成立，而不是只要求全局平均超过 50%。块数配额在每个领域内按同一比例分配，从而不让 health、general、coding 的任务差异与上下文长度混在一起。

4. 分层构造流程

STAGE 1冻结基础记录

读取 v2.1 的 15,000 条记录，验证 ID、来源、领域和隐藏原子不变。

STAGE 2领域内分配 K

按锁定配额为每个领域分配完全相同比例的 3–20 块分布。

STAGE 3重组真实原子

把真实原子分配到单原子或多原子块，保持每个原子恰好映射一次。

STAGE 4隔离 Hard A

canonical Hard A 始终独占一个可见块，不与辅助噪声混合。

STAGE 5补足辅助 A

生成同一场景内的 1–2 个独立原子，直到达到 K 和 ceil(K/2)。

STAGE 6确定性门

检查 ID、短语锚点、域泄漏、映射、标签动作和原子对关系。

STAGE 7独立语义 QC

逐原子、逐块、全局检查 query relation、答案足迹、原子性和同用户合理性。

STAGE 8发布准入

只接纳 strict 或明确 non-blocking review；reject/invalid 禁止进入。

实现无关伪代码

for each domain:
    assign block counts using the locked long-tail quota

for each record:
    freeze question, lineage, grounded atoms, labels, and canonical Hard A
    K = assigned visible-block count
    M = ceil(K / 2)
    partition grounded atoms into coherent blocks
    keep canonical Hard A as one singleton block
    add same-user zero-footprint A blocks until:
        visible_block_count == K
        multi_atom_block_count == M
    require every hidden atom to map to exactly one visible block
    run deterministic validation

run independent semantic QC on every accepted record
retry only structurally invalid QC outputs
directly repair the audited semantic tail
admit strict and non-blocking review only

6. 独立语义质检

独立 QC 不重新判断已冻结的 B/C 或 canonical Hard A。它只验证新增加的辅助 A 原子是否同时满足以下条件：

  1. 与当前问题的 query relation 为 absent；
  2. 正确回答中的 content、presentation、implementation 和 safety footprint 均为 none；
  3. 不需要显式纠正；
  4. 每个原子可独立判真或判假；
  5. 同一块内的多个原子构成一致场景；
  6. 全部辅助块合在一起不会形成可合法影响答案的用户人格。

7. 两条语义尾部如何修复

问题诊断修复复核
多个收藏场景形成过强“整理者人格”各原子独立无足迹，但整体颜色与收藏行为过于相似。保持块数、原子 ID 和 A 标签不变，将场景分散为鸟类观察与通勤记录。strict pass
人类家居记忆与“海豚用户”冲突辅助噪声触发必须纠正的身份矛盾，不再是零足迹 A。保持结构不变，改为海洋研究围栏中的识别与 enrichment 历史。strict pass

两条修复逐原子记录 before/after 文本与 SHA-256，并由同一独立 QC 协议重新判定；没有手工把 reject 改成 pass。

9. 审阅时应保留的限制

  • v2.2 的长尾负载是受控实验分布，不宣称等同于任一线上记忆系统的自然流量分布。
  • 新增辅助 A 是模型辅助生成并经过确定性与独立模型 QC，不等同于完全人工标注。
  • A 原子显著增多是负载设计的直接结果。论文应同时报告块级上下文负载和原子级 A/B/C 分布，不能只报告一个比例。
  • 现有七模型结果基于 v2.1 固定两块接口；不能直接当作 v2.2 长尾接口的模型结果。
  • 医学来源仍包含许可证 unknown 的上游数据；当前 release 仅用于内部研究审阅和训练，不代表可公开再分发。
