**参考答案（对回答模型隐藏）：**

该 DIY 自托管方案与团队现实不匹配。资金有限的创业团队若维护本地服务器、端口
转发和动态 DNS，会把工程时间消耗在基础设施维护与安全风险上，并产生隐藏成本。
项目主要使用 Java 和 JUnit，因此平台需要可靠支持 JVM 构建生命周期、测试报告、
缓存和环境管理，而不是只提供通用脚本执行。团队跨两个国家分布，本地单机与住宅
网络还会形成可用性和访问瓶颈。修正策略是选择托管式或云原生 CI 服务，要求它原生
支持 Java/JUnit、能为分布式团队提供高可用访问，并减少基础设施维护负担。
