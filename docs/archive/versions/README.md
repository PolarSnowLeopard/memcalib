| 版本 | 主要变化 | 文档入口 |
|---|---|---|
| v2.3 | 复合记忆块、3–20 块长尾、三档难度、隐藏原子长尾 | [v2.3](v2.3/) |
| v2.2 | 可见记忆块数量长尾扩展 | [v2.2](v2.2/) |
| v2.1 | 多领域基础集、ordered-usage 评测协议 | [v2.1](v2.1/) |
| v2.0 | 多领域构建与早期交付 | [v2.0](v2.0/) |

早期设计提案位于 [`docs/archive/construction-designs/`](../construction-designs/)，实施计划位于 [`docs/archive/plans/`](../plans/)。

历史文档中的路径、哈希和统计是生成时快照。目录迁移不会回写旧 manifest；如需运行当前流程，应使用 [`docs/current/v2.4/`](../../current/v2.4/) 和仓库根 README。
