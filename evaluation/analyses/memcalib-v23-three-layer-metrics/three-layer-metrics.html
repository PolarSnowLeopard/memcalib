MemCalib v2.3 three-layer evaluation

Existing Judge outputs only. Every aggregate gives each answer sample equal weight.

Overall: SCS(0.5). Directional: sOPB/sUPB(0.5). Guardrails: Any-OPB/Any-UPB.

Detailed calculation

1. Ordered atom errors

For each scorable atom, map r(A)=0, r(B)=1, r(C)=2. Internal A construction subtypes are not exposed to the metric.

o(s,i) = max(r(predicted) - r(gold), 0)
u(s,i) = max(r(gold) - r(predicted), 0)

2. Sample budgets

Sum all scorable atoms across every memory block within one answer sample.

O(s) = sum_i o(s,i)
U(s) = sum_i u(s,i)
T(s) = O(s) + U(s)

Block and atom counts do not directly become model-level weights; they increase the number of opportunities for error.

3. Overall primary metric

SCS(s; rho) = rho^(O(s)+U(s))
SCS(rho) = mean_s SCS(s; rho)
Primary rho = 0.5

Total budgets 0, 1, 2, 3, and 4 receive scores 1, 0.5, 0.25, 0.125, and 0.0625. Higher is better.

4. Directional primary metrics

sOPB(s; rho) = 1 - rho^O(s)
sUPB(s; rho) = 1 - rho^U(s)
sOPB(rho) = mean_s sOPB(s; rho)
sUPB(rho) = mean_s sUPB(s; rho)

Lower is better. Repeated and two-level errors receive more weight, while each sample remains bounded below 1.

5. Directional H

R(O) = 1-sOPB; R(U) = 1-sUPB
Directional H = 2*R(O)*R(U)/(R(O)+R(U))

Higher is better. This compact summary never replaces the two directional columns.

6. Event guardrails and exact accuracy

Any-OPB = mean_s 1[O(s)>0]
Any-UPB = mean_s 1[U(s)>0]
Exact = mean_s 1[O(s)+U(s)=0]

Any rates measure error coverage, collapsing one and many errors to the same event. Event H is the harmonic mean of their two resistance terms.

7. Aggregation and uncertainty

Every answer sample has one equal model-level vote. The 95% intervals use 2,000 sample-cluster bootstrap replicates and the 2.5th/97.5th percentiles. Paired comparisons resample the same sample IDs on both sides and report after - before.
