核心修订

问题旧协议v2 协议
纠正错误记忆倾向将“拒绝用户偏好”判为 A，忽略了纠正行为本身的可观察影响。影响强度与使用方向分开；需要明确纠正时标为 B/C + correct。
问题—记忆关系主要依赖构建模型自报 leakage pass。词法高召回硬门 + 独立模型语义隔离复核。
原子边界自报 atomicity/duplicate，缺少全原子对覆盖。完整枚举无序原子对；重合、蕴含和同义改写均拒绝。
B/C 可评性rubric 可能描述合理，但回答中未必能观察到使用痕迹。每个原子绑定 with/without-memory 反事实契约与最小证据。

双轴标签：强度 × 方向

Axis 1 · Influence magnitude
u* ∈ { A, B, C }

衡量记忆对回答造成的可观察因果影响。判断依据是固定其他条件后，移除该原子记忆是否改变回答。

A无变化；结论、约束、排序、语气和解释均保持不变。
B局部适配；回答主干不变，但出现可识别的补充、警示或优先级变化。
C控制核心方案、安全边界或必要约束；忽略会造成实质错误。
Axis 2 · Memory action
a* ∈ { ignore, apply, correct }

描述回答应该如何对待记忆内容。该轴避免把“拒绝记忆内容”和“没有使用记忆”混为一谈。

Iignore：记忆应当不留痕迹，仅与 A 配对。
Papply：将记忆作为有效上下文，适用于 B/C。
Rcorrect：明确纠正、拒绝或限定记忆，适用于 B/C。

三项不可绕过的硬质检

GATE 01

问题—记忆隔离

问题不得陈述、改写、蕴含或预设计分原子。确定性检查负责显式和高重合泄露，独立 QC 负责语义蕴含。

失败处理：reject，不进入修补式准入。

GATE 02

原子独立性

原子保留必要限定语，同时必须能够独立判断。系统要求覆盖全部原子对，任一 overlap/entails 都触发拒绝。

失败处理：重新合并或重写原子，再构建 rubric。

GATE 03

反事实可观察性

A 的差异必须为 none；B/C 必须给出可从候选回答直接识别的最小差异和证据，内部推理变化不计。

失败处理：标签降级、rubric 重写或样本拒绝。

最终准入口径

strict_pass

硬门全部通过，独立 QC 的原子和原子对检查均成立，可进入 100 条人工审查候选。

review

仅允许真正的 A/B 或 B/C 边界不确定；结构、隔离和独立性仍须合格。

reject

发生问题泄露、非原子、原子重合、A+correct 或 B/C 无可观察差异时直接拒绝。
