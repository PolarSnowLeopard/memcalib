# MemCalib v2.4.1 非思考主评测：三层样本级指标

本报告只使用已经完成的 8,892 条主 Judge 判断，不再调用回答模型或 Judge。每个模型在同一组 494 条样本上同时评测 full-memory 和 no-memory；论文主表使用 full-memory。

## 1. 记号与评分单位

对样本 `s`：

- `I_s`：样本中可评分原子的集合；
- `i`：一个原子的索引；
- `y(s,i)`：原子 `i` 的金标准标签；
- `ŷ(s,i)`：Judge 根据模型回答判定的实际使用标签；
- `r(A)=0, r(B)=1, r(C)=2`：A/B/C 的有序等级；
- `N=494`：每个模型和条件下的样本数。

样本内的过用预算和少用预算定义为：

```text
O(s) = Σ[i ∈ I_s] max(r(ŷ(s,i)) - r(y(s,i)), 0)
U(s) = Σ[i ∈ I_s] max(r(y(s,i)) - r(ŷ(s,i)), 0)
```

因此，相邻等级错误增加 1 个预算单位；A→C 或 C→A 的跨两级错误增加 2 个预算单位。预算先在一条样本内部累积，再对样本等权平均。原子多的样本可以更难，但不会因为原子多而在模型级汇总中获得更大的样本权重。

## 2. 三层主口径

### 总体主指标：SCS

固定 `ρ=0.5`：

```text
SCS(s) = 0.5 ^ (O(s) + U(s))
SCS    = (1/N) × Σ[s] SCS(s)
```

SCS 越高越好。无错误样本得 100%；总预算为 1、2、3 时分别得 50%、25%、12.5%。它衡量一条回答的总体可靠性，但不能说明错误来自过用还是少用。

### 方向主指标：sOPB 与 sUPB

```text
sOPB(s) = 1 - 0.5 ^ O(s)
sUPB(s) = 1 - 0.5 ^ U(s)
sOPB    = (1/N) × Σ[s] sOPB(s)
sUPB    = (1/N) × Σ[s] sUPB(s)
```

两者越低越好。它们区分一次错误与多次或跨两级错误，但每条样本的单方向风险上限为 100%，避免少数超长样本无限支配模型均值。

### 事件率护栏：Any-OPB 与 Any-UPB

```text
Any-OPB(s) = 1，当 O(s) > 0；否则为 0
Any-UPB(s) = 1，当 U(s) > 0；否则为 0
Any-OPB    = (1/N) × Σ[s] Any-OPB(s)
Any-UPB    = (1/N) × Σ[s] Any-UPB(s)
```

两者越低越好。它们只回答“有多少样本至少发生一次该方向错误”，不能区分一次轻微错误与多次严重错误，因此只作为覆盖面护栏。

`Exact` 是 `O(s)+U(s)=0` 的样本比例，越高越好。

## 6. 解释边界

- SCS 是总体主指标，但必须与两个方向主指标同时报告。
- sOPB/sUPB 是论文解释模型“过度服从记忆”和“未充分使用记忆”的主要方向指标。
- Any 指标容易随原子数增加而饱和，只用于显示错误覆盖面。
- Directional H、原子级 H、MinCalib、MCC、Kappa、CVaR、PMU、Rasch 和 pairwise 结果属于补充诊断。
- 不应根据单一综合分数宣称一个模型全面优于另一个模型；方向取舍和区间重叠必须保留。
