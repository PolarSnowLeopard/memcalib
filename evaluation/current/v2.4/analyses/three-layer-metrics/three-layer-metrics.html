MemCalib v2.3 three-layer evaluation

Existing Judge outputs only. Every aggregate gives each answer sample equal weight.

Overall: SCS(0.5). Directional: sOPB/sUPB(0.5). Guardrails: Any-OPB/Any-UPB.

Detailed calculation

1. Units, index sets, and notation

Definitions apply to one fixed model m and condition c. Their superscripts are suppressed below. Each i is a flattened pair (b,j), retaining both its memory-block and block-local atom identity.

Unscorable atoms are excluded. A response with no scorable atoms is structurally invalid, not a zero-error sample. Compared buckets must use identical sample-ID sets.

2. Ordered atom errors

A means no atom-specific answer footprint; B means bounded local support or correction; C means material control over the answer. The labels encode required influence, not truthfulness. Map r(A)=0, r(B)=1, r(C)=2. Internal A construction subtypes are not exposed to the metric.

o(s,i) = max(r(predicted) - r(gold), 0)
u(s,i) = max(r(gold) - r(predicted), 0)

3. Sample budgets

Sum all scorable atoms across every memory block within one answer sample.

O(s) = sum_{i in I(s)} o(s,i)
U(s) = sum_{i in I(s)} u(s,i)
T(s) = O(s) + U(s)

Block and atom counts do not directly become model-level weights; they increase the number of opportunities for error.

4. Overall primary metric

SCS(s; rho) = rho^(O(s)+U(s))
SCS(rho) = (1/N) sum_{s in S} SCS(s; rho)
Primary rho = 0.5

Total budgets 0, 1, 2, 3, and 4 receive scores 100%, 50%, 25%, 12.5%, and 6.25%. Higher is better.

5. Directional primary metrics

sOPB(s; rho) = 1 - rho^O(s)
sUPB(s; rho) = 1 - rho^U(s)
sOPB(rho) = (1/N) sum_{s in S} sOPB(s; rho)
sUPB(rho) = (1/N) sum_{s in S} sUPB(s; rho)

Lower is better. Repeated and two-level errors receive more weight, while each sample remains bounded below 1.

6. Directional H

R(O) = 1-sOPB; R(U) = 1-sUPB
Directional H = 2*R(O)*R(U)/(R(O)+R(U))

Higher is better. This compact summary never replaces the two directional columns.

7. Event guardrails and exact accuracy

Any-OPB = (1/N) sum_{s in S} 1[O(s)>0]
Any-UPB = (1/N) sum_{s in S} 1[U(s)>0]
Exact = (1/N) sum_{s in S} 1[O(s)+U(s)=0]

Any rates measure error coverage, collapsing one and many errors to the same event. Event H is the harmonic mean of their two resistance terms.

8. Display scale, aggregation, and uncertainty

Metrics are computed on [0,1], displayed as percentages, and paired differences are displayed in percentage points.

Every answer sample has one equal model-level vote. The 95% intervals use 2,000 sample-cluster bootstrap replicates and the 2.5th/97.5th percentiles. Paired comparisons resample the same sample IDs on both sides and report after - before.
